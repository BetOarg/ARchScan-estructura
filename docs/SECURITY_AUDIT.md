# Auditoría de seguridad de ARchScan

La verificación automatizada controla la ausencia de secretos y firmas de producción, el uso exclusivo del permiso de cámara, la ausencia de ubicación y seguimiento, las capacidades opcionales de AR/cámara, la marca ARchScan y la persistencia local sin credenciales de servicios externos.

Ejecutar `dart run packages/room_scanner_app/tool/security_audit.dart` desde la raíz.

La auditoría no reemplaza pruebas físicas, revisión de dependencias ni validación de las declaraciones de privacidad.
